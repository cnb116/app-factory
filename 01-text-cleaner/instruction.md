# 지시서 형식

* 프로젝트/작업명: app-factory 01호 — 텍스트 정리기 (1초 글자수 계산 + 공백정리기)
* 목표: 검증된 유틸리티 벤치마킹 방식으로 1호기 웹앱 제작, 결제 흐름까지 포함한 완성형 데모 확보
* 현재 상태 / 문제: `01-sample/` 빈 폴더만 존재. 실제 코드 없음
* 원하는 결과:
   1. `01-sample/` 폴더를 `01-text-cleaner/`로 이름 변경
   2. 그 안에 Next.js + Tailwind CSS로 웹앱 제작:
      * 화면 중앙에 큰 텍스트 입력창
      * 아래에 [글자수(공백포함/미포함)], [단어 수] 실시간 표시
      * [불필요한 공백/줄바꿈 1초 정리] 왕버튼 (검정 배경, 노란 글씨, 큰 사이즈)
      * 맨 밑에 노란색 왕버튼: [프리미엄 AI 맞춤법 교정기 열기 - 3,900원] — 클릭 시 "결제 준비 중입니다" 알림창 표시 (실제 결제 연동 아직 없음)
   3. `instruction.md`에 이 지시서 내용 그대로 저장 (원본 시방서 보관용)
   4. `app_inventory.md`에 01호 행 추가:
      * 번호: 01
      * 앱 이름: 텍스트 정리기
      * 배포 URL: (미배포)
      * 핵심 기능: 글자수/단어수 계산, 공백 정리
      * 결제 상태: 테스트(가짜 알림창)
      * 폴더 경로: app-factory/01-text-cleaner
      * 수정 이력: 2026-08-30 최초 생성
* 제약 조건:
   * 50대 이상 사용자 고려 — 버튼 최대한 크게, 고대비 색상(검정/노랑)
   * 복잡한 메뉴 없이 단일 화면 구성
* 연결/연동 대상: 없음 (결제는 가짜 알림창으로 대체)
* 대상 저장소/브랜치: `github.com/cnb116/app-factory`, main
* 배포 여부: 코드 작성만
* 커밋 메시지 규칙: "[app-factory] 작업 내용 요약" 형식 사용 (예: "[app-factory] 01호 텍스트 정리기 초기 생성")
